# تجربة شاشة الفصل العائمة (Maxhub / BenQ)

## المرحلة 1 — صفحة ويب على الشاشة (جاهزة)

1. على شاشة فصل واحدة: افتح Chrome/المتصفح.
2. سجّل دخول بحساب **مشرف هذا الفصل**.
3. ادخل: `/display/class` أو من لوحة الفصل اضغط **شاشة العرض**.
4. اضغط **تفعيل الصوت** مرة واحدة (مطلوب في أندرويد).
5. اطلب من ولي أمر إرسال طلب خروج لابن في نفس الفصل.
6. راقب: ظهور الطلب + صوت النغمة + تتبّع الحالة.

شاشة البهو (بدون تطبيق عائم): `/display/lobby` بحساب المشرف العام.

## المرحلة 2 — التطبيق العائم (Android Overlay)

المجلد: [`android-overlay/`](../android-overlay/)

تطبيق Kotlin خفيف يعمل في الخلفية. عند طلب جديد لهذا الفصل تظهر **نافذة فوق الشرح** + صوت.

### المتطلبات

- Android Studio (أو SDK + JDK 17)
- حساب **مشرف الفصل** المرتبط بالفصل على الشاشة
- صلاحية النظام: **الظهور فوق التطبيقات الأخرى** (Display over other apps)

### 1) إعداد مفاتيح Supabase

من جذر المشروع:

```bash
bash android-overlay/scripts/sync-supabase-config.sh
```

ينسخ `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` من `.env` إلى  
`android-overlay/local.properties` (لا ترفع هذا الملف إلى Git).

أو انسخ يدوياً من `android-overlay/local.properties.example`.

### 2) بناء APK

**الأسهل:** افتح مجلد `android-overlay` في Android Studio → Sync → Build → Build APK(s).

أو من الطرفية (بعد توليد `gradlew` عبر Android Studio مرة واحدة):

```bash
bash android-overlay/scripts/build-debug.sh
```

الملف الناتج:

`android-overlay/app/build/outputs/apk/debug/app-debug.apk`

### 3) التثبيت على شاشة الفصل

```bash
adb install -r android-overlay/app/build/outputs/apk/debug/app-debug.apk
```

أو انسخ الـ APK إلى الشاشة وثبّته يدوياً (قد تحتاج تفعيل «مصادر غير معروفة»).

### 4) الصلاحيات والتشغيل

1. افتح تطبيق **خروج — عرض الفصل**.
2. سجّل دخول بحساب مشرف **هذا** الفصل.
3. اضغط **منح صلاحية الظهور فوق التطبيقات** وفعّلها للتطبيق.
4. اسمح بالإشعارات إن طُلب ذلك (Android 13+).
5. اضغط **تفعيل النافذة العائمة**.
6. اترك إشعار المراقبة ظاهراً وارجع لتطبيق الشرح/السبورة.
7. أرسل طلب خروج لابن في نفس الفصل → يفترض تظهر نافذة عائمة + صوت.

### ماذا نختبر على الجهاز؟

على BenQ أو Maxhub افتح:

`الإعدادات → التطبيقات → الوصول الخاص / الظهور فوق التطبيقات`

وتأكد أن النظام يسمح بمنح هذه الصلاحية لتطبيق طرف ثالث.

| النتيجة | المعنى |
|---------|--------|
| الصلاحية موجودة والنافذة ظهرت فوق الشرح | المرحلة 2 نجحت لهذا الجهاز |
| الصلاحية غير موجودة أو مقفولة بالإدارة | التطبيق العائم لن يعمل → استخدم تابلت صغير أو صفحة `/display/class` |

### إيقاف المراقبة

من التطبيق: **إيقاف المراقبة**، أو من إشعار الخدمة، أو تسجيل الخروج.

## المرحلة 3 — بعد نجاح التجربة على فصل واحد

- نسخ نفس الـ APK لباقي الفصول (كل شاشة بحساب مشرف فصلها)
- الإبقاء على شاشة البهو كـ kiosk ويب
- صقل الصوت والنافذة حسب ملاحظات المعلمين

## ملاحظات

- الحساب المستخدم = حساب مشرف الفصل (نفس صلاحيات الطلبات الحالية).
- الجلسة تُحفظ على الجهاز؛ لا تشارك شاشة الفصل مع حسابات أخرى.
- المراقبة تعتمد على استعلام كل ~8 ثوانٍ (موثوق على الشبكات المدرسية بدون WebSocket معقّد).
- الطلبات المقبولة/المرفوضة تُحدَّث على النافذة إن كانت ظاهرة، وتختفي بعد ثوانٍ.
